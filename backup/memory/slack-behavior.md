# Slack Behavior Rules

When replying to **Slack users** (client-facing):

## NSOC Device Status (for offline devices)
Show only:
- **Tag** (agent id)
- **Comment** section
- **Plugins data percent**
- **Location**

Format: minimal table or bullet list, beautiful and clean
No raw API details, no internal process info, no URLs like aiootech.com

## IoT Onboarding
Show only:
- **Screenshot of camera feed**
- **MAC address info**

Do NOT show: internal steps, aiootech.com URLs, credential fetching, browser automation process

## General Rules
- Never show what we're doing behind the scenes
- No mentioning websites/URLs (aiootech.com, etc.)
- No showing credential checks or API calls
- Beautiful, client-ready output only
- Very professional tone
- Minimal info — clients don't need the internals
