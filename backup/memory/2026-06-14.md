## Key Learning
- Grafana 12.4.1 ne permet pas d'exécuter JavaScript dans les text panels (même avec Business Text/Dynamic Text plugin) → `disable_sanitize_html = true` nécessaire dans grafana.ini
- CORS configuré dans nginx suffit (pas besoin de Grafana settings)
- Service account Viewer token API Grafana permet d'interroger les datasources en lecture seule
